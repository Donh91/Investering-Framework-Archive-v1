**Status:** NAVIGATION_ONLY  
**Authority:** NONE_BY_ITSELF  
**Folder role:** Public, redistributable source material and provenance context that may support research but does not automatically become framework doctrine.

Raw/normalized restricted provider values, private source-health evidence and restricted captures belong in `Donh91/secrets` under the cross-repository boundary.


## High-value mission seeds

### 1. Provenance audit

Find important framework claims whose original public source, timestamp, extraction path or version can no longer be reproduced.

### 2. Source freshness / replacement

Identify sources that are stale, discontinued, changed method or have a better primary authority available.

### 3. Claim extraction discipline

For TechDev, research reports and external analysis, separate exact source claims from framework inference and from later outcome knowledge.

### 4. Source duplication

Find multiple copies/extracts of the same underlying evidence and prevent duplicate counting.

### 5. Rights / storage boundary

Flag sources whose terms make durable storage, redistribution or derived use unclear. Do not solve rights ambiguity by silently archiving more data.

## Authority ceiling

Default mode is `READ_ONLY`.

Do not promote source claims into framework rules from this folder. Route substantive evaluation through Research Lab and existing governance.

Do not copy restricted values into this public repository even if a model can access them elsewhere.

## Astra-class challenge

A stronger model can add value here by tracing a framework belief all the way back to primary evidence and identifying exactly where interpretation entered the chain.

Prefer primary sources, reproducible extraction and explicit uncertainty over a large source corpus.
