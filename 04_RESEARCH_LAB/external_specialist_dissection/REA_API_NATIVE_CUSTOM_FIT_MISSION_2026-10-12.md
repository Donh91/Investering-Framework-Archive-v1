## 4. Main scientific test: Capital Lifecycle without an engine

Test three preregistered *questions*, using existing studies as owners:
H1: independent qualified wallets are observed **before** publicity and add forward, realizable predictive value over market-age/liquidity/momentum.
H2: wallet entity exit/egress precedes meaningful downside or sellability failure and adds useful warning beyond price/volume.
H3: repeatable wallet/entity success survives winners+losers, one-hit controls, incomplete histories, public copying delay and fees.

Strict event schema:
`chain_id, ca/mint, venue/pool, block, tx/log, event_time, first_source_time, available_to_framework_time, wallet_label_effective_time, cutoff, completeness, evidence_ref/hash`.
`eligible_at = max(first_source_time, available_to_framework_time, wallet_label_effective_time)`.
Token recipient != initiator; transfer != bought/sold; related != same owner; common CEX != entity; observed wallet action != publicly copyable alpha.
Wait for first post-activation Pons first-ten *fully preserved frozen eligible cohort*. If no eligible complete case -> `WAIT_FORWARD_COHORT`, NEVER manufacture historical prospective credit.
Compare same timestamp/same cohort/same cost:
champion public visibility/price/volume/age/liquidity;
challenger + pre-cutoff independent Wallet Alpha entity/retention/exit evidence.
Include negative controls: matched ordinary launch, loser/rug, unlabeled wallet, one-hit wallet, shuffled wallet labels, after-attention entry, infrastructure-only cluster and custody-only outflow.
Measure precision/recall with sample size/uncertainty, lead time, false positive and missed winner costs, net realizable post-slippage/fees outcomes at $500/$2,000 when route proof exists, MAE/MFE, maximum loss, win/loss concentration, attention lag and **abstentions/UNKNOWN**.
No superiority claims without source-confirmed PIT, complete denominator, held-out forward outcomes and independent acceptance. Historical cases can diagnose but not earn prospective edge credit.
