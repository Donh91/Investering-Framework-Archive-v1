# Adaptive Pullback Learning: suspended classification

The existing owner `ELIGIBILITY_STATUS_v1.json` is consumed by the runtime.
Its current status is `SUSPENDED_NO_ELIGIBILITY_CONTRACT`.

Valid fresh observations and descriptive adaptive statistics continue. Mechanical
pullback/reload classification, new episodes and maturation of existing episodes
are off. `REGIME_NOT_ACTIVE` reports this suspension; it is not a bearish market
call. The output includes `ELIGIBILITY_CONTRACT_UNAVAILABLE`, the owner path and
its exact-byte hash.

The retired Entry state, proxy breadth, source quality, T12 and direction
confidence cannot grant eligibility. Missing, malformed or incompatible owner
status blocks new collection, classification and episode mutation and publishes
an explicit unavailable status. Legacy Entry evidence itself is optional context,
not permission to collect the independently authorized descriptive observations.

Duplicate and older price observations do not create or rewrite observations.
They still refresh the current suspension/authority view. Existing observation
and episode files remain unchanged, and new observation paths use exclusive
creation. Missing matched returns remain missing in the descriptive percentiles.

Resumption requires the separate source-backed specification and framework-owner
review listed by the existing status owner. This implementation cannot infer
resumption from a renamed status, a legacy state or changed configuration flags.
No portfolio, rebuy, market-state or automatic rule authority is introduced.
