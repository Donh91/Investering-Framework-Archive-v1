## Lock clarification

Receipt and audit of a package are permitted during accumulation. The following remain prohibited until the readiness gate opens:

- executing the supplied backtest;
- executing its bootstrap;
- parameter selection;
- rule or threshold promotion;
- active falsifier registration;
- forecast-ledger creation;
- portfolio or market-state inference.

The package materially improves future test design, but it does not change the Backtest Build phase.
