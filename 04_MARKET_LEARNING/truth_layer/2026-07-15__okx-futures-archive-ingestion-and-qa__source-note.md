## 5. Scope limitation

The following historical datasets are designed by the exporter but are not embedded in this package:

- historical mark-price candles;
- historical index candles;
- historical OI;
- historical funding;
- historical long/short account ratio;

## 6. Validator scope defect

The bundled `scripts/validate_archive.py` searches only for:

```text
normalized/*/*_1h.csv
```

The embedded seed files are named:

```text
swap_history_1h_seed_100.csv
```

As a result, running the validator against the package root verifies checksums but returns an empty `hourly_files` list. The pre-generated `validation_report.json` is correct, and independent validation reproduced its seed continuity claims, but the standalone validator does not itself rediscover the seed CSV files.

Classification:

```text
DATA_INTEGRITY: PASS
PACKAGE_CHECKSUMS: PASS
EMBEDDED_VALIDATION_REPORT: PASS_REPRODUCED_INDEPENDENTLY
STANDALONE_VALIDATOR_COVERAGE: PARTIAL
ROOT_CAUSE: FILENAME_GLOB_SCOPE
```

No source file is silently changed. A future source-package revision may widen the glob or add an explicit seed validation mode and then regenerate package checksums and version metadata.

## 7. GitHub workflow boundary

The bundled workflow is preserved as a reference inside the source-material folder. It is not activated under the repository's live `.github/workflows/` path by this ingestion.

Reason:

- activating or changing GitHub workflows is a high-impact operation;
- the current workflow uploads a 90-day artifact but does not permanently commit collected data;
- a downloaded run artifact must still pass independent governance ingestion before becoming canonical truth-layer data.

This archive action therefore preserves the reproducible workflow without changing repository automation.
