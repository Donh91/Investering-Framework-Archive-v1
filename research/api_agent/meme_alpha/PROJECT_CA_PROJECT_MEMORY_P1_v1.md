# Project -> CA P1 Project Memory

Status: SHADOW_ONLY / RESEARCH_ONLY

This is the bounded P1 child substrate required by `PROJECT_CA_INTELLIGENCE_BRIDGE_SHADOW_BUILD_CONTRACT_v1`.

It freezes a unique eligible project trial before token existence, preserves point-in-time source observations, keeps no-token trials, and creates append-only supersession lineage. Project identity is anchored only by bounded control roots. Names, tickers, logos and aliases are stored as non-authoritative metadata.

P1 deliberately does **not** implement Project -> CA binding, material-change routing, A/B/C comparison, Jev, outcomes, alerts, portfolio actions or trading. Pons/factory token occurrence therefore cannot become a high-confidence project binding through this module.

Focused regression coverage includes the required 8-Ball no-token case and HoodStack contradictory mutable-source case.
