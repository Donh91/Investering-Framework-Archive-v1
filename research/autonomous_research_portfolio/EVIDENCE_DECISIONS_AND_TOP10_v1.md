## Scoring and selection method

Ex ante rubric, explicitly not empirical backtest success:

| Criterion | Weight |
|---|---:|
| Incremental prediction/decision value potential | 25% |
| Testability, historical and prospective source availability | 20% |
| Accumulating forward-learning value | 15% |
| Fit with existing GitHub runtime | 15% |
| Cross-framework reuse | 10% |
| Cost efficiency | 10% |
| Implementation simplicity | 5% |

Individual numeric criterion scores and exact weighted sums are in `PORTFOLIO_MANIFEST_v1.json`. **86.5, 82.3, 81.4, 79.4, 75.6** are human-reasoned *priority estimates*, with uncertainty ±9, ±13, ±14, ±17, ±15 points respectively. Pairwise ordering of #2-4 is not statistically meaningful. Execution order should favor the genuinely source-ready/cheap and unblock shared dependencies before engaging expensive models.

### Overlap decision versus HRE and existing owners

`HRE (historical truth tape + replay + false controls)` -> `Task2/#1827 (time admission + original issue)` -> `owner experiments with frozen baseline` -> `original due-only maturity and Strategist independent falsifier` -> `original owner PR + CI + governance` -> `S1 eligible closure only`.

ARP-01 consumes HRE but does NOT make another replay system. ARP-03 reuses Market Anticipation/EDGE and does NOT create another Global Liquidity Observatory. ARP-04 stays inside private Alpha Lab and cannot publish sensitive token/wallet data to public Archive. ARP-05 extends existing News P0 and is not another source crawl. ARP-02 improves whether any warning/action *matters*, without claiming trade authorization.

Cross-cutting source integrity is a necessary gate in all five, **not a sixth engine**. Historical replay supplies development counterexamples, not original event-time issuance or historical trade fills. The program's most important negative result can be `REJECTED` with the avoided maintenance bill.

## Budget and actual autonomy boundary

Forecast 72, Utility 64, Transition 64, Alpha 144, News 60 Actions minutes per month = **404 planned compute minutes**, plus estimated 40 validation and 110 safety/rescan buffer = **554**, rounded up to an ARP *soft research ceiling of 600 min/month*. This is a **planning assumption for incremental standard runner use**, not actual observed billable minutes; free/public/private multipliers, runner type, failed retries, heavy data/host quotas and source rate limits may dominate. Under the owner's stated 3,000-minute budget, leave the other 2,400 to production and existing owners. Never create an independent ARP recurring workflow: run only admitted, bounded jobs inside eligible existing PR/on-demand workflows or existing owner scheduled lanes, using 2-3 independent compute jobs when source-legal.

**Paid AI default: $0.** Existing Grok Bridge for optional source-bound adversarial review only when actually callable and independently verified. Sol MAX only for a specifically released, SHA-frozen #1476 authorized mission under present native per-call/cumulative budget and no-ambiguous-retry policy. Not allowed automatically by general /GOAL, no paid API already used for this ARP.

**Autonomy reality tiers**:
1. **SUPPORTED / VERIFIED:** Existing original owners, RPL skill, some past HRE native compute runs, private Alpha research owner loops and deterministic archive/source contracts.
2. **BUILT BUT NOT AUTO-CONSUMED:** ARP manifest/recipes and evidence queue on a feature branch after creation, later index/PR if released. A machine queue file cannot execute tasks.
3. **UNPROVEN:** Five newly operating portfolio programs, genuine natural hourly S1 first-to-last owner original PR creation/test/merge/main/consumer readback in this ARP mission, Grok independent report, Sol paid run and prospective trading edge.
4. **HARD-GATED:** Private restricted data rights, Round3 experiment-analysis switch, original source first-published time, official forecasts/thresholds and any live trade action.

A native success receipt may prove one Actions computation; it never proves 24/7 background AI autonomy. Any item lacking source/time proof remains `AWAIT_MATURITY` or `SCIENTIFIC_BLOCK`, not fabricated `PASS`.
