## Core design rule

The program must distinguish:
- contemporaneous explanation from genuinely leading information;
- levels correlation from return prediction;
- broad regime context from tradable timing;
- causal pathway evidence from visually persuasive coincidence;
- discovery samples from sealed holdout periods;
- market-wide signals from crypto-specific transmission.

No track may be promoted merely because it explains a known move after the fact.

## Success definition

A track is useful only if it adds stable out-of-sample information beyond the existing framework, improves calibration or early-warning lead time, and survives regime, source and specification challenges without hidden look-ahead.
