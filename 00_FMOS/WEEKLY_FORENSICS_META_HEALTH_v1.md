# WEEKLY FORENSICS + META-HEALTH v1

Owner: Framework Learning Supervisor. Issue: #1177.

This is an advisory integration capability, not a new market engine, supervisor, repair queue, or portfolio executor.

## Inputs
Consume existing point-in-time/frozen artifacts from their current owners. Missing/UNKNOWN evidence stays UNKNOWN. Pullback eligibility suspension is binding.

## Modules
Pullback/Re-entry, Forecast/Decision, Rotation/Transmission, Agent/Automation Meta-Health, Learning/Experiment Maturation, Data/Evidence Integrity.

## Health dimensions
Runtime health, evidence health, consumption health, outcome health are distinct. Successful execution alone does not prove useful consumption or outcome value.

## Routing
Every actionable finding routes to exactly one of:
SELF_HEAL_SAFE, DETERMINISTIC_REPAIR, SOURCE_OWNER, SPECIALIST_AGENT, RESEARCH_EXPERIMENT, CODEX_REQUIRED, GOVERNANCE_REVIEW, WAIT_FOR_EVIDENCE, HUMAN_AUTHORITY, NO_ACTION.

The existing remediation-maturation machinery remains the sole repair queue. Findings must be deduplicated/supersession-checked before work is created.

## Authority firewall
No canonical market effect, portfolio execution, BUY/SELL threshold mutation, model-weight mutation, budget-guard relaxation, or automatic shadow-to-canonical promotion.

## Scheduling
PRELIMINARY may run before Sunday close to identify evidence gaps. FINAL must run only after the completed weekly close/freeze is available. Master Monday receives only the compact advisory delta.

## Compute
Deterministic first. Escalate only for material, novel, causally ambiguous findings. Codex is reserved for bounded code changes.
