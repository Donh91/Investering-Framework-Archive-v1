# Framework Intelligence & Learning Loop v1

Status: ACTIVE_RESEARCH_ORCHESTRATION_WHEN_MERGED  
Authority: RESEARCH / LEARNING / ORCHESTRATION ONLY  
Canonical market authority: NONE  
Portfolio authority: NONE  
Scientific authority: NONE  
Master Monday authority: ADVISORY_ONLY_UNTIL_SEPARATE_PROMOTION_GATE

## Mission
The framework must compound useful knowledge without creating a second source of truth. Existing owners keep raw evidence, forecast/outcome accountability, experiment lifecycle, scientific admission, Unified Adjudication and Compounding Learning. This layer compresses those authoritative products into durable cross-week memory, detects information that is unused or contradictory, routes bounded work to specialists, and prepares a provenance-bound advisory packet for Master Monday.

## Ownership
- Experiment Lifecycle + Scientific Admission own prospective experiment state.
- Unified Adjudication owns what mature experiment evidence means.
- Compounding Learning owns semantic-family learning strategy and next-best experiment proposals.
- Framework Learning Supervisor owns cross-system memory, information-utilization review, method-staleness detection, specialist routing and Master Monday advisory preparation.
- Master Monday remains the weekly calibration owner.
- Cycle Navigator remains presentation-only.

The Supervisor MUST reference existing products instead of copying or replacing their authority.

## Three loops
1. MARKET LEARNING: evidence -> experiment/outcome -> adjudication -> Compounding Learning -> compressed memory.
2. MASTER MONDAY INTELLIGENCE: frozen weekly evidence + compressed memory + contradictions -> consultation packet -> Master Monday.
3. META LEARNING: unused information + repeated conflicts + stale assumptions + specialist utility + cost -> bounded delegation / method audit / experiment proposal -> existing governance routes.

## Evidence classes
Every conclusion is one of:
- NOW: current verified evidence.
- LEARNING: accumulated descriptive/prospective research understanding.
- PROVEN: only claims admitted by the governing scientific contract.

LEARNING MUST NOT be silently promoted to PROVEN.

## Persistent memory
The Supervisor maintains semantic-family memory with:
- first and last observed week;
- current family state;
- matured / observation counts where available;
- duplicate-adjusted identity;
- supporting, negative, inconclusive and contested evidence state;
- negative-memory reopen condition;
- current regime transferability when evaluable;
- provenance pointers to authoritative sources.

Negative evidence is first-class memory. Previously unsupported ideas may be reopened only for materially new regime, data, mechanism or implementation.

## Weekly learning delta
Each completed week classifies material family changes as:
- NEW
- STRENGTHENED
- WEAKENED
- FALSIFIED_OR_NEGATIVE
- CONTESTED
- UNCHANGED
- UNRESOLVED

Raw candidate counts are never treated as independent support.

## Specialist mesh
Logical specialists:
- RANGE_LAB_ANALYST
- SEQUENCE_REGIME_ANALYST
- ROTATION_ANALYST
- LEVERAGE_MICROSTRUCTURE_ANALYST
- LIQUIDITY_MACRO_ANALYST
- EXPERIMENT_FAMILY_CURATOR
- CONTRADICTION_ANALYST
- ACCOUNTABILITY_ANALYST
- INFORMATION_UTILIZATION_ANALYST
- METHODOLOGY_AUDITOR
- COST_MODEL_GOVERNOR

A specialist is a bounded role, not new authority. Multiple specialists interpreting one frozen observation do not create multiple evidence events.

## Delegation states
Allowed Supervisor outputs:
- NO_ACTION
- OBSERVE
- DELEGATE_DETERMINISTIC
- DELEGATE_SPECIALIST
- PROPOSE_EXPERIMENT
- ROUTE_TO_CODEX
- REQUEST_METHOD_AUDIT
- REQUEST_STRONG_MODEL_AUDIT
- WAIT_FOR_EVIDENCE
- DEDUPLICATED
- CLOSED_LEARNED

Code work MUST use the canonical research-to-Codex / remediation route. Market hypotheses MUST use Experiment Lifecycle + Scientific Admission. Method changes MUST use a versioned methodology proposal. The Supervisor may not create a parallel execution authority.

## Compute policy
Always choose the cheapest sufficient route:
1. deterministic analysis;
2. cheap specialist model;
3. Sol/Terra-class reasoning when material uncertainty remains;
4. strongest-model audit only for high-value architecture, scientific-method or unresolved cross-system conflicts.

Strong-model use is never the routine default.

## Master Monday consultation
The Supervisor produces `MASTER_MONDAY_LEARNING_PACKET_v1` with compact advisory fields:
- strengthened;
- weakened;
- new learning;
- negative findings;
- contradictions;
- range context;
- 4/8-week memory when supported;
- method-improvement candidates;
- scientific status.

During Phase 1 this packet is shadow-only and MUST NOT alter live Master Monday or Cycle Navigator. A later explicit promotion gate is required.

## Method improvement firewall
A repeated useful learning finding may become `METHOD_IMPROVEMENT_CANDIDATE`, but never an automatic rule change.

Required route:
learning finding -> Methodology Auditor -> adversarial review -> prospective/incremental-value test when applicable -> versioned methodology proposal -> governed acceptance -> Master Monday method vNext.

Historical Master Monday outputs are never rewritten to improve apparent performance.

## Information-utilization register
The Supervisor records high-value information that exists but is not being consumed correctly, including source, expected consumer, reason unused, severity and proposed route.

## Method-staleness register
Staleness is event-driven, not age-only. Triggers include source/schema changes, improved owner data, obsolete fallbacks, repeated contradictions, experiment maturation, materially changed cost/capability, or scientific defects.

States:
- REVIEW_NOT_NEEDED
- MONITOR
- METHOD_AUDIT_DUE

## Disagreement protocol
Material specialist disagreement becomes `AGENT_CONFLICT`. It is decomposed into factual, methodological, evidence-class, horizon or regime disagreement. No majority voting and no averaging away conflict.

## Scientific firewall
Forbidden:
- retrospective forecast creation;
- retroactive rescoring to improve performance;
- hindsight threshold search presented as prospective;
- duplicate candidates counted as independent evidence;
- legacy/descriptive evidence mixed into confirmatory evidence;
- future leakage;
- negative evidence deletion;
- automatic market-rule / model-weight / threshold / portfolio promotion.

`FORECAST SKILL = UNPROVEN` remains binding until the accepted confirmatory contract says otherwise.

## Cadence
- Daily lightweight Supervisor scan: memory health, unconsumed information, method staleness, delegation queue.
- Monday post-adjudication synthesis: weekly learning delta + Master Monday advisory packet.
- Monthly deeper methodology review may be proposed, but is not self-authorizing.

## Fail closed
Missing authoritative inputs remain missing. The Supervisor may emit partial products with explicit unavailable fields, but may not silently substitute later or unrelated evidence.

## Success criterion
The system is successful when it reduces repeated research, preserves negative learning, increases use of already-collected information, improves Master Monday interpretation over time, controls compute cost and remains scientifically auditable without manual babysitting.
