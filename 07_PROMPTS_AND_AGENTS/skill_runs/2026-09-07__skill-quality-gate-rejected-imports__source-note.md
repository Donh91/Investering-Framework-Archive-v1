# Skill Quality Gate Rejected Direct Imports

**Dato:** 2026-09-07  
**Status:** SOURCE_NOTE  
**Område:** agent skill architecture  
**Primary folder:** `07_PROMPTS_AND_AGENTS/skill_runs/`

Direct imports deliberately rejected for the initial implementation:

- `i-have-adhd`: useful output and eval ideas, but global style rules would over-constrain audit/evidence work.
- `qiaomu-meta-skill`: useful prior-art/generalization mechanisms, but overlapping authoring/publishing authority and project-specific branding make direct installation inappropriate.
- `j-rig-skill-binary-eval`: valuable methodology, but external runtime dependency is unnecessary for the initial framework-local gate.
- `obra/superpowers`: strong individual disciplines, but importing the full SDLC framework would overlap existing routing and remediation governance.
- `Thisisjuke/source-skill`: strong provenance/reuse rules, but overlaps `developer-source-research`.

Policy: adapt mechanisms only after framework-local evaluation. External repositories remain source evidence, never runtime authority.
