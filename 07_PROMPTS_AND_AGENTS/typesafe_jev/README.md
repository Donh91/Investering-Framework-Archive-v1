## Pilot order

1. static contract validation and source pinning;
2. sanitized smoke test after credential installation;
3. frozen historical Alpha Lab triage replay with outcomes hidden from Jev;
4. compare against current baseline and System One Adapter challenger;
5. measure false negatives, evidence loss, calibration, latency and cost;
6. only then consider a narrowly bounded live shadow route.

## Promotion ceiling

A successful pilot may justify a further forward test. It does not create BUY/SELL authority, automatic trade authority, market-state authority, canonical signal weight, or permission to drop uncertain evidence.

Low certainty in a high-value or asymmetric research context routes to retention/escalation, not silent deletion.
