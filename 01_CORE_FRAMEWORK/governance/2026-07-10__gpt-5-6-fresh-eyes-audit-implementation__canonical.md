## 2. Current framework truth

```text
DATA PING = evidence and verified state capture
MAIN FRAMEWORK = interpretation, permissions, action and ratification
SHADOW / RESEARCH LAB = challenger and learning only
MASTER MONDAY = weekly official synthesis after ratification
CYCLE NAVIGATOR = public output and pre-registered accountability
GITHUB = versioned memory and governance control plane
```

Infrastructure is not evidence of edge.

A rule is not functioning merely because it is written, indexed or named. A functioning rule must do at least one of the following:

1. change a decision;
2. block a bad promotion;
3. produce immutable rows;
4. improve a benchmarked result;
5. reduce a documented failure mode.

## 3. Binding corrective decisions

### 3.1 Range and precision claims

```text
RANGE_EDGE_STATUS: NOT_SUPPORTED_AGAINST_SIMPLE_ATR_BASELINES
PUBLIC_RANGE_PRECISION_MARKETING: SUSPENDED
PUBLIC_TRACK_RECORD_STATUS: LOCKED_PENDING_INDEPENDENT_RECONCILIATION
BLENDED_PRECISION_SCORE: FORBIDDEN
```

Until forward rows demonstrate otherwise, do not use:

- `88% range precision`;
- `price forecast accuracy` as a broad edge claim;
- `track record proves edge`;
- historical score bars that appear independently verified;
- one blended score where phase strength hides range weakness.

Range, phase, rotation, warning, timing, insurance, FNP and baseline delta must remain separate.

### 3.2 Defensive versus offensive evidence

```text
DEFENSIVE_EDGE_STATUS: PARTIALLY_SUPPORTED / CONTINUE_MEASUREMENT
OFFENSIVE_EDGE_STATUS: HYPOTHESIS / NEEDS_DIVERGENCE_ROWS
BTC_PERMISSION_LANE: SEPARATE_FROM_ALT_PERMISSION_LANE
```

BTC and large-cap permission must not automatically inherit every ecosystem or microcap lock.

This separation does not unlock live buying by itself. It authorizes only the existing BTC-partial forward test and asset-tiered evaluation.

### 3.3 Missing data

```text
DATA_MISSING_MEANS: UNKNOWN
DATA_MISSING_MEANS_BEARISH: NO
DATA_MISSING_MAY_BLOCK_PERMISSION: YES
```

Acronyms and named concepts outside these families remain features or historical notes unless they have a definition, owner, row type, decision effect, evidence state and kill criterion.
