## Purpose

Test whether the July discovery primitives add incremental information on future natural M6 opportunities without changing current Compass or M6 warning semantics.

## Owner

Current M6 Lane C event/outcome contract remains the only primary prospective owner. This protocol is a shadow decomposition of eligible future observations, not a second warning engine.

## No July-derived numeric fitting

This protocol does not create new numeric thresholds from the July cases. It may consume only already-canonical/frozen owner states or future separately preregistered transformations whose thresholds are frozen before their observations.

If an A-level cannot be computed from legitimate current owners without inventing a threshold, it is UNKNOWN.

## Same-opportunity comparison

For each eligible future M6 observation:
- same event anchor;
- same legal information cutoff;
- same price tape;
- same maturation horizons;
- same episode family;
- same data-health requirements;
- same outcome vector.

A0-A3 are evaluated as information sets, not portfolio actions.

## Outcome vector

Use the frozen M6 Event Outcome Contract:
24h, 72h, 7d, 14d, 30d terminal return, MAE, MFE, time to extrema, adverse barrier touches, completeness and family identity.

No favorable threshold is introduced.

## Incremental questions

Q1 Does A1 discriminate adverse outcomes better than A0?
Q2 Does A2 add information beyond A1?
Q3 Does A3 add information beyond A2?
Q4 Do M1/M2 materially condition the result without becoming post-hoc filters?
Q5 Does M3 correctly prevent overconfidence when required inputs are unavailable?

## Statistical discipline

Primary inferential N is independent episode families, never repeated warnings.
No p-value or probability calibration until sample geometry supports it.
No threshold search.
No best-cell reporting.
No composite optimization.
All negative and UNKNOWN observations persist.
If sample is too small, verdict is NEED_MORE_DATA.

## Action firewall

No A0-A3 state maps to SELL, TRIM, allocation, re-entry or current Compass state.
An information primitive must first survive prospective incremental testing.
Any later action test requires a separate byte-frozen policy and economic counterfactual contract.

## Promotion

A primitive can move from NOMINATED to PROSPECTIVE_INFORMATION_CANDIDATE only if:
1. exact owner semantics are frozen before observations;
2. enough independent families exist for a non-anecdotal comparison;
3. incremental value survives the simpler prior level;
4. result is not driven by degraded/missing data;
5. no material leakage or selection defect remains.

No primitive in this protocol currently meets those conditions.
