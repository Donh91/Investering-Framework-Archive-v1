## Objective

Test whether point-in-time wallet/entity intelligence and precursor events add incremental, realizable information beyond simple public market visibility for fresh-token discovery.

This experiment is explicitly designed to answer four questions:

1. Does Wazz-style wallet/entity context add predictive value beyond price/volume/liquidity/age?
2. Can the Robinhood strategy contract 0x53a42d2d0fdd60bf8f833fb94841349095a74024 be reconstructed into an auditable target-event -> action -> exit episode ledger?
3. Can the target-wallet cohort or upstream precursor state be observed early enough to create public, lawful, time-sensitive review value without copying manipulative execution?
4. Can Alpha Lab measure model-vs-realized execution fidelity so that theoretical signal quality is never conflated with actual tradeability?

### B2. Critical attribution rule

0x53a4...4024 is EXECUTOR/STRATEGY_CONTRACT unless future direct evidence proves otherwise.

Do not label it smart money / whale.

Infrastructure such as routers, pool managers, bridges, CEX paths and relays must be tagged INFRASTRUCTURE before wallet/entity inference.

### B3. Cohort objective

Identify the alleged 33 target wallets only from:
- exact observable causal relationship;
- repeated contract reaction after a wallet's public event;
- external list only as lead until independently reproduced.

For each target-wallet candidate track:
- age;
- balance/capital class;
- median ticket size;
- token categories;
- pre-move vs post-move entry tendency;
- target event -> crowd propagation lag;
- post-target 5m / 30m / 1h / 6h / 24h outcomes;
- failures/rugs/unsellable outcomes;
- recurrence;
- independence/service/funding checks.

### B4. Main hypothesis

A subset of public wallet or upstream precursor events provides repeatable lead time before broader Robinhood token repricing, and that lead time retains positive realizable value after fees/slippage/failures.

### B5. Falsifiers

Kill or downgrade if:
- target wallets cannot be independently reconstructed;
- observed advantage depends on private/non-public intent;
- contract acts before a public-eligible signal;
- edge is explained by a few inaccessible/unsellable outliers;
- top episodes dominate and median expectancy is non-positive after costs;
- public disclosure materially destroys the edge;
- matched random/naive momentum baseline performs similarly;
- router/infrastructure misclassification explains apparent wallet linkage;
- required execution resembles sandwich/front-running or otherwise violates allowed research boundaries.

### Evidence qualification

Candidate evidence can include:
- multiple independent historically useful wallets converging before broad propagation;
- an upstream event that deterministically precedes the later token action;
- repeat entity-cluster behavior with point-in-time support;
- known target-wallet precursor with measured lead time.

Disallowed:
- one wallet alone;
- current wallet reputation projected backwards;
- KOL/social label alone;
- same router/factory/pool alone;
- retrospective winner selection.
