## Generation lifecycle
1. **Refresh**: record UTC, exact default-branch commits (and active original PR heads) in public-safe form, source clocks, current cockpit, AGENTS, cross-repo boundary, canonical context router, #1512/#1157/#1156 and original contracts. Re-read latest Bridge privately; never export private logs or data. Read previous Frontier generation and existing audit/OSS/learning artifacts. If a new domain appears, add a hypothesis only after owner discovery. If removed, mark retired with source. Preserve historical generations.
2. **Inventory change**: compare previous snapshot to fresh snapshots by changed paths AND semantic capability/consumer. Revalidate prior gaps and claims; track new, resolved, superseded, invalidated, unverified. Existing work has precedence. Do not mistake stale health artifacts for current runtime truth. Do not treat unavailable evidence as absence. Re-read exact head before any implementation handoff. No mutable latest pointer as sole provenance.
3. **Research**: default 2–10 independent question lanes; use direct read-only tool concurrency if available, report actual execution mode. Seek primary papers, official project docs, actual OSS code/commit/license and counterevidence. Search by missing mechanism, not popularity. Record original publication date, access date, source identifiers, license and scope, prior catalog overlap, transfer assumptions. Documentation is not empirical validation. No installations or untrusted code execution by default. Read licenses and dependency/supply-chain risks before copying; method reimplementation when incompatible.
4. **Falsify**: baseline first, freeze clocks, task/episode families, held-out cases, metric, practical effect, uncertainty, negative controls, cost/stop rule. Synthetic examples are engineering evidence only; prospective market experiments remain subject to Scientific Admission and Round 3 firewall. No self-promotion, no current trading/forecast policy changes. Grade A replicated direct evidence, B controlled limited evidence, C exploratory or implementation reference, D unsupported claim; grade external evidence separately from local transfer proof.
5. **Novelty triage**: ALREADY_IMPLEMENTED, IN_PROGRESS, PARTIAL_GAP, NOVEL_CANDIDATE, EXPERIMENT_REQUIRED, REJECTED, UNVERIFIED. Search existing original PR diffs, methods, tests, remediation/Research Lab queues and failed history. Do not claim a gap from title alone. Distinguish verified gap from proposed test target. Dedup by mechanism + owner + input/output + test family. No new queue: #1512 existing dispositions and cap THREE active research-to-implementation handoffs apply. No parallel writers or branch hijacking. When full, defer or attach to existing owner as advisory, not new dispatch.
6. **Publish**: one immutable dated generation report with source snapshots, lane execution/coverage and limitations, prior-generation delta, new source evidence, proposals and actual outcome status. Prefer docs-only isolated PR with exact head and reviewer request. Add link in existing Research Lab discovery surface/issue, not new canonical registry. Any correction is a dated addendum or subsequent reviewed commit; no historical rewriting.
7. **Review & route**: Claude independently checks overlap, counterexamples, feasibility, evidence grades and exact head. Existing Strategist gives canonical disposition; S1 routes to existing owner/original PR only, with real queue/cost/CI/governance constraints. A comment is not an execution receipt. No duplicate requests if same content/version consumed. Do not edit Bridge's Claude-owned branch.
8. **Adaptive follow-up**: on future owner-requested audit, reconcile previous recommendation IDs against actual production readback and outcome evidence, retire failed or superseded ideas, update next hypothesis based on measured uncertainty. Compare before/after using fixed denominator and equivalent tasks. No forced novelty, unchanged evidence => NOOP. Retain negative/null results. Archive references to original receipt/owner rather than duplicating ledgers. If blocked, exact observable reactivation condition. Long-running work only through already authorized tasks and their contracts.

## Lane menu (adapt, do not blindly repeat)
- Learning transfer: selective memory/skill uplift and negative transfer, independent holdouts.
- Agent cooperation: blind review, false agreement and net marginal reviewer contribution.
- S1 reliability: transaction state, repeated trials, idempotency and recovery.
- Research conversion: maturity -> routed -> acted -> observed effect; avoid metrics gaming.
- Forecast intelligence: causal signal perturbation, calibrated uncertainty, interval sharpness, time/episode grouping.
- Economic intelligence: executable after-cost edge, opportunity costs, selection/multiple testing.
- Resource economics: marginal cost per verified outcome, deterministic baseline and latency.
- End-to-end integration: source->consumer, stale/dropped fields, runtime verification.
