## Batch simulation protocol
Stage 0: audit existing 834 candidate inventory without assuming backlog = failure; current active registry and original owner dedup, no new experiment until scope distinct. Read original replay datasets and previous outcomes; only legal admitted nonlocked data. 
Stage 1: deterministic smoke on synthetic fixtures and small public historical development slice; hash manifest (source, cutoff, membership, code, params, seeds, cost assumptions, label, splits), test no-lookahead and clock perturbation. No scientific inference from fixtures. 
Stage 2: nested chronological walk-forward train/validate/test with purge at least overlapping target span and embargo chosen from dependence; reserve untouched final holdout, leave-one-era-out development where available. Historical 2017, 2018, 2020, 2021, 2022–23, 2024–26 are candidate regimes, not independent replicates; use only supported data. Same horizons, denominators and asset/venue identity. Pretrained model possibly saw all history: no claim truly OOS without verified cutoff; future-only prospective test. Use block bootstrap by market episode/era and robust uncertainty; record effective N and abstention. 
Stage 3: staged budget: 2–6 model families x 5–25 predeclared configurations x 25–150 windows as illustrative upper design (up to 22,500 evaluations, not independent N); initial small local run first. Record complete trial universe including failures. Use reusable cache keys with source+code+params+clock+split digest, deterministic seeds, vectorized computation, no giant repo-generated data or extra Actions dispatch. Cap by existing authorized available CPU/minutes; USD0 incremental paid API. If compute unavailable mark BLOCKED and exact trigger, no implied run. 
Stage 4: freeze smallest surviving challenger before untouched admitted holdout; correct multiplicity across selected families, avoid peeking; prereg effect sizes/power based on independent episodes, no arbitrary pass based on 30 correlated observations. Proposed decision: outperform simplest predeclared comparator by practical margin with uncertainty consistent with improvement, calibration/coverage noninferior, no risk/lineage regression. Exact thresholds and sequential/stop rules set by #1596/#1157 before outcomes, never retroactive. 
Stage 5: prospective shadow only after original admission; no locked Round 3 outcomes. Preserve existing incumbent, do not promote on historical fit. Stop/kill leakage, incomplete denominator, impossible cost/exit, source rights violation, inadequate sample, no marginal gain, safety failure. Report nulls. No forced winners.
