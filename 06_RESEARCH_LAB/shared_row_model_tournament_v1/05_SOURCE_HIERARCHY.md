# Source Hierarchy

Free-first order is frozen:

1. Already archived GitHub owner-grade data.
2. Free primary provider or exchange data with deterministic timestamps.
3. Free controls/proxies only as separately named controls, never silent replacements.
4. Bounded paid data only after a Value-of-Information memo proves the exact missing timestamps can realistically change the terminal verdict.

Alternative.me Fear & Greed may only be a sentiment control and may not be renamed CFGI. Paid CFGI or CoinGlass are not authorized at initialization. Deep Research is a bounded gap-recovery reserve, not a broad data source.
