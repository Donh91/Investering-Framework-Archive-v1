## Purpose

This archive answers the original Shadow Layer question at full scope:

> Which old and new non-canonical sensors, shadow signals, meta-layers and research-only components actually contain useful, reproducible and incremental information, and which are redundant, weakly evidenced, regime-specific, timing tools, veto tools or currently untestable?

The review deliberately treats the Shadow Registry as the population anchor, not the 14 recovered legacy sensors as the whole universe.

## Research architecture

The work is separated into independent adversarial workstreams which were cross-checked before synthesis:

1. **Registry / archaeology workstream** - inventory current registry families plus older shadow-only components recovered from archived framework material.
2. **Historical evidence workstream** - separate contemporaneous observed data from later narrative and historical synthesis.
3. **Effectiveness workstream** - assess predictive, diagnostic, veto, timing and regime-classification value.
4. **Redundancy / dependence workstream** - identify sensors which are transformations of the same latent information.
5. **Opportunity-cost workstream** - include false negatives and late confirmation, not only false positives.
6. **Data-value workstream** - preserve and prioritize expensive / scarce historical evidence already captured by DATA PING, Claude research and CFGI-related packets.
7. **Adversarial synthesis workstream** - downgrade conclusions when provenance, sample size, exact semantics or negative controls are insufficient.

These workstreams are analytical roles, not separate authority holders. Final conclusions are conservative by construction.

## Core evidence rule

Evidence is ranked:

1. Timestamped machine-readable repository observation with stable source identity.
2. Timestamped repository research row / forward-test row with immutable definition.
3. Archived DATA PING / ledger output containing contemporaneous inputs.
4. Historical research package containing timestamped or source-bound data.
5. Later replay / retrospective reconstruction.
6. Narrative claim without reproducible event rows.

A lower-ranked source can generate a research lead but cannot overrule a higher-ranked source.
