## 4. Decision framework and empirical gates

Astra must independently rank the six alternatives A-F in original H06 using the precommitted 100-point weighted rubric. Scores are intervals when source evidence is incomplete. Hard veto: loss of critical role, private-data leak, unauthorized paid action/merge, false PIT/live forecast, forged receipt or claiming autonomous success without a natural run.

Seven-day feasibility audit may only confirm source, tooling, cadence, safety and delivery, not genuine forecast/alpha lift. Prefer one read-only CRE controlled pilot with baseline/fallback, then a 28-day operational comparison against its own original due events and source outcomes:
1. **Correct duty coverage**: expected due work vs verified work, no missing critical original receipts, with UTC/Copenhagen alignment.
2. **Verified closures**: closed with actual applicable downstream natural consumer proof, not comments, reports or CI alone.
3. **Signal-to-noise**: avoid duplicate GitHub comments/reads; count material unique findings and abstentions, including false negative silence.
4. **Cost**: actual task/API/tool cost when observed, not prompt size or declared rate; no new paid routine provider.
5. **Safety**: zero unauthorized write or authority promotion, zero false PASS, zero source/PIT rewrites, no private outputs.
6. **Owner involvement**: track human interventions per eligible action and review-gated decisions separately; do not game by not finding work.
7. **Robustness**: invalid hashes, stale source, tool/REST/DNS failure, partial pages, repeated task runs, shared identity spoof, source-owned path changes, host notification variation.

Propose quantitative stop rules BEFORE tests: any safety regression or missed critical due work => rollback. A 50% reduction in duplicated *unnecessary* reads/comments is a possible stretch objective only with measured baseline and unchanged coverage; it is NOT a finding. Do not promote learned memory, forecast parameters, source authority, or trading based on task-runtime efficiency.
