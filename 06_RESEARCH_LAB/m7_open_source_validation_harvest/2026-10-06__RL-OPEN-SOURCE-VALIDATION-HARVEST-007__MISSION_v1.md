### High-value missing or not yet generalized

G1. Event-label contract
Need a generic, frozen event-outcome schema for warning/action research:
- event anchor;
- vertical horizon;
- adverse barrier;
- favorable barrier;
- first-touch ordering;
- MFE/MAE;
- terminal return;
- concurrency/overlap identity;
- cost/fill semantics.

G2. Purge/embargo dependency contract
Purge must derive from the longest information dependency, not an arbitrary fixed number.

G3. Non-overlapping / clustered uncertainty
Repeated warning observations from one market episode must not masquerade as independent N.

G4. Probability calibration layer
If M6 eventually produces a warning-risk probability, calibration must be measured before any action mapping. Candidate metrics: Brier/reliability/calibration curve. No threshold optimization until preregistered.

G5. Backtest-overfitting accounting
For families with many variants, trial count and PBO/DSR-style diagnostics should be available when statistically appropriate. This complements M4's missing global proposal denominator.

G6. Tail-risk utility
M6 should evaluate not only mean return but catastrophic-drawdown avoided, CVaR/tail loss, opportunity cost, peak giveback and re-entry friction.
