# Native readback trigger map

The following phrases are UI/readback aliases, not requests for manual data collection:

- `Kompas` / `Handlekompas`: latest verified native Handlekompas plus concise market/action interpretation.
- `Status`: latest native state delta + machinery health.
- `Data Ping`: latest native state audit/readback; do not require pasted data.
- `CN`: current Cycle Navigator authority package plus contextual native state; live data cannot rewrite frozen weekly public state.
- `OTA`: latest Native OTA state; extra research only on adaptive gate or explicit request.

If native state is DEGRADED, report the degradation. Never ask the user to repair routine source data manually when an automated owner/recovery path exists.
