# CN_LOGO - Cycle Navigator logo reference

Date: 2026-10-14
Status: User-selected visual identity for ongoing Cycle Navigator design exploration. This does not approve either concept layout or authorize production deployment.

## Visual description
A compact compass mark to the left of a two-line uppercase wordmark.

- Outer compass circle: fine deep-navy ring.
- Inner compass circle: pale cool-grey ring.
- Center needle: small geometric blue and navy compass pointer, not a conventional multi-point compass rose.
- Wordmark: CYCLE on the upper line in widely tracked regular uppercase; NAVIGATOR below in larger bold, tracked uppercase, both dark navy.
- Color references: navy #07172f, blue #3977e4, neutral cool grey.
- Background: clean white/off-white; understated institutional appearance.
- The proportions of the icon and two-line wordmark should remain consistent across desktop and narrow iPhone headers.
