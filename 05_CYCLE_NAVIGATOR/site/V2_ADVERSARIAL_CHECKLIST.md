- [x] Missing historical score fields render unavailable rather than zero.
- [x] Manual and frozen prospective eras are not aggregated into a synthetic all-time score.
- [x] LIVE prices cannot mutate the weekly package.
- [x] Missing canonical public snapshot uses bounded fallback rather than fresh inference.
- [x] Public snapshot strips repository identity and internal week path.
- [x] Three-choice mobile navigation only.
- [x] Generic market pulse is context below action layer, not the product hero.
- [x] PATH is explicitly conditional.
- [x] HOW IT WORKS omits thresholds, weights, prompts and complete source mappings.
- [ ] PR CI run passes on exact final head.
- [ ] Deployed artifact readback matches merged source.

Unchecked items are release gates, not permission to infer success.
