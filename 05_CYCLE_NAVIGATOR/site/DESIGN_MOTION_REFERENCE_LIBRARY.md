## Apply to Cycle Navigator
1. Prioritize typography, spacing, understandable chart annotations and sparse motion.
2. Write frame-specific motion briefs and review contact sheets before acceptance.
3. Test iPhone Safari and reduced-motion. All animations must be presentation only.
4. Never let animation imply financial certainty, stage confirmation or unsupported timing.
5. Evaluate licensing, security and performance before adoption; retain native HTML/CSS/JS when appropriate.
6. Keep all CN official state, historical frozen forecast and score semantics unchanged.
