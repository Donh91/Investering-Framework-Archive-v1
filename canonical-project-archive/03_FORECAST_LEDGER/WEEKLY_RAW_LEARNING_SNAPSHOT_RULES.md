Status: Active operational rule
Date added: 2026-07-05
Effective from: 2026-07-05
Source context: ChatGPT
Applies to: Weekly RAW, Forecast Ledger, Master Monday

## Executive summary

Weekly RAW Learning Snapshot prepares the short-term learning input before Master Monday.

## Canonical content

Each weekly snapshot should review:

- open RAW 1-3d rows
- open RAW 5-7d rows
- open RAW 2-3w rows if relevant
- verified weekly BTC range
- verified weekly ETH range
- intraday blocks
- range accuracy status
- direction status
- timing status
- main miss reason
- calibration adjustment

## Source rule

Use the highest active DATA PING version for live context.
Use verified actual ranges for scoring.
Do not use DATA PING snapshots as verified actual ranges.

## Operational implication

Master Monday should read this snapshot before final synthesis.

## Governance notes

If actual range data is missing or conflicting, mark PRICE_UNVERIFIED and exclude exact range scoring.
