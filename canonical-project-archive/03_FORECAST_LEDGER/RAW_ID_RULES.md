# RAW ID RULES

Status: Active rule
Date added: 2026-07-05

## Rule

Every RAW row needs a stable ID before later review.

## ID format

RAW-[horizon]-[YYYYMMDD]-[number]

Examples:

RAW-1_3D-20260705-01
RAW-5_7D-20260705-01
RAW-2_3W-20260705-01

## Required fields

- horizon
- creation date
- source context
- base BTC
- base ETH if used
- expected range
- expected sequence
- invalidation
- drivers
- confidence
- status

## Rule

Do not edit the original row after creation. Add review notes later.
