# CYCLE NAVIGATOR ROTATION LANGUAGE STANDARD

Status: Canonical communication rule
Date added: 2026-07-05
Effective from: 2026-07-05
Source context: ChatGPT
Applies to: Cycle Navigator, Altcoin Cycle, Altseason Countdown, public captions

## Executive summary

Altseason must not be presented as one broad undefined event.

Cycle Navigator should describe rotation as a staged timeline.

## Staged language

Use this sequence:

1. No Rotation.
2. BTC-only relief.
3. Early Rotation Watch.
4. Selective Alt Rotation.
5. Broad Altseason.
6. Parabolic / Microcap Mania.

## Core rule

Do not collapse early rotation watch, selective rotation and broad altseason into the same label.

## Operational implication

Public communication should reduce hype and improve precision.

When rotation is unconfirmed, say exactly what is missing:

- ETH/BTC persistence
- breadth survival
- BTC dominance deceleration
- deployment quality
- multi-day survival
