# DRAFT TO PUBLISHED HANDOVER RULE

Status: Active rule
Date added: 2026-07-05

## Rule

Master Monday creates the first Cycle Navigator draft.

After edits, the final X version may differ from the draft.

Only the final version published on X belongs in published-x-posts.

## Workflow

1. Master Monday draft is created.
2. User edits the post.
3. Final X version is published.
4. User provides final version from X or Grok.
5. Final version is archived here.
6. Draft remains draft history, not public record.

## Governance

Do not overwrite the published version with a draft.
Do not overwrite a draft with the published version.
Keep both roles separate.
