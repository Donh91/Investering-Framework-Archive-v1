# CYCLE NAVIGATOR RANGE SCORING CALIBRATION

Status: Canonical calibration update
Date added: 2026-07-05
Effective from: 2026-07-05
Source context: ChatGPT
Applies to: Cycle Navigator scoring, verified actuals, range evaluation

## Executive summary

Historical range scoring should be interpreted carefully.

Weekly high/low overlap can make precision look better than daily containment actually was.

## Canonical learning

Range scoring should distinguish:

- weekly overlap
- daily containment
- intraday block quality
- upper/lower boundary breaches
- direction accuracy
- structure accuracy

## Calibration rule

Old scores should not be retroactively rewritten.

Add calibration notes when a prior scoring method is later judged too optimistic.

## Operational implication

Future Cycle Navigator scoring should be more transparent about whether price merely touched the range or respected the structure.

## Governance notes

Verified actuals should come from reliable sources such as user-verified Yahoo Finance or CoinGecko checks when available.
