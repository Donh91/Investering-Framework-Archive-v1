# CYCLE NAVIGATOR CANONICAL STANDARD

Status: Canonical
Date added: 2026-07-05
Effective from: 2026-07-05
Source context: ChatGPT
Applies to: Cycle Navigator, public weekly posts, scoring, templates

## Executive summary

Cycle Navigator is the public-facing weekly output of the Investering framework.

It must preserve history, communicate clearly and separate market state, forecast, actual result and model learning.

## Required weekly record

Each weekly Cycle Navigator record should preserve:

- post number
- week number
- date range
- forecast
- actual
- BTC range
- ETH range
- intraday blocks if used
- cycle phase
- rotation state
- model evaluation
- final public text
- template version
- verified data source
- scoring notes

## Core rule

Do not retroactively rewrite old public posts.

If old scoring is later judged optimistic, preserve the original score and add a calibration note.

## Operational implication

Cycle Navigator is both public communication and historical performance record.
