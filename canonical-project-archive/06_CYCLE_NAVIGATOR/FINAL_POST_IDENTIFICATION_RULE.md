# FINAL POST IDENTIFICATION RULE

Status: Active archive rule
Date added: 2026-07-05
Effective from: 2026-07-05
Source context: ChatGPT + user instruction
Applies to: Cycle Navigator historical posts, X-post archive, Archive Sync

## Executive summary

Cycle Navigator final X-posts must be preserved as public track record.

A post is treated as final when it is the latest available version for that week after variations, edits and changes stop.

## Canonical rule

For each Cycle Navigator week:

1. Find all draft, variation and revision material in the project archive.
2. Identify the latest available complete social_post or final X-post version.
3. Treat that latest complete version as the final public post unless the user explicitly rejects it.
4. Preserve it without rewriting.
5. Add a metadata header and source note.
6. If only a summary exists, archive as source summary and mark full text pending extraction.

## Do not do this

- Do not rewrite old posts.
- Do not silently improve old wording.
- Do not recalculate old scores.
- Do not replace final posts with later standards.
- Do not call a draft final if a later complete version exists.

## Governance notes

Historical posts can receive calibration notes, but the original public post text stays frozen.
