Applies to: Cycle Navigator visuals, infographics, image prompts

## Executive summary

Cycle Navigator visuals should feel like an institutional research dashboard, not a crypto influencer graphic.

## Core visual principles

- clean light background
- institutional mood
- high signal density
- low text density
- strong hierarchy
- large whitespace
- readable on mobile
- professional before flashy

## Locked sections

1. Track record.
2. Previous week performance.
3. Upcoming week outlook.
4. Cycle / rotation state.
5. Key takeaway.

## Content rule

The image should be understandable in a few seconds and still reward deeper inspection.

## Operational implication

Visual continuity matters. Future graphics should evolve slowly and keep the same layout logic across weeks.
