# MASTER MONDAY TO CYCLE NAVIGATOR LINKS

Status: Active linking rule
Date added: 2026-07-05

## Purpose

Connect each Master Monday run to the Cycle Navigator output it produced.

## Link chain

Master Monday run
-> CN draft
-> user edits
-> published X post
-> verified actuals
-> score and learning

## Required links

For each completed week, preserve:

- Master Monday run file
- CN number
- draft status
- published X post file
- actual range source
- score status
- calibration note if needed

## Rule

The published X post is the public record.
The Master Monday run is the decision record.
Both should remain separate but linked.
