## Executive summary

The Investering framework is layered.

Each layer has a different purpose and authority level.

## Layer map

DATA PING:
Truth-layer sensor input and market snapshot feed.

Forecast Ledger:
Accountability layer for RAW rows, ranges, outcomes and calibration.

Sequence/PTR:
Path and progression layer for sequences, pullbacks and returned states.

Research Lab:
Audit, challenge, falsification and opportunity-cost testing.

Shadow:
Learning memory and early diagnostic layer.

Master Monday:
Weekly synthesis and framework state consolidation.

Cycle Navigator:
Public-facing communication and performance history.

GitHub:
Long-term archive and continuity layer.

ChatGPT:
Framework governance and ratification layer.

## Operational implication

Do not let lower-authority layers silently override higher-authority governance.

## Governance notes

Layer separation protects the framework from source drift and model overreach.
