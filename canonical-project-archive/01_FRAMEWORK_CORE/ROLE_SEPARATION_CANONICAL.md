# ROLE SEPARATION CANONICAL

Status: Canonical
Date added: 2026-07-05
Effective from: 2026-07-05
Source context: ChatGPT
Applies to: framework roles, models, archive, weekly operations

## Executive summary

Each model and system has a separate role.

Role separation prevents overreach and keeps the framework auditable.

## Canonical roles

Custom GPT DATA PING:
Sensor input and structured market snapshot feed.

ChatGPT:
Framework brain, governance, ratification and synthesis.

Claude:
Research Lab, audit, replay and hypothesis testing.

Grok:
Shadow context, adversarial comparison and external critique.

TechDev:
Macro compass and cycle reference, not execution override.

GitHub:
Versioned long-term archive and continuity memory.

Automations:
Scheduled execution shell, not independent authority.

User-verified actuals:
Highest-priority actual data when available.

## Operational implication

A source can inform the framework without controlling it.

## Governance notes

Do not treat external model output or automation output as truth-layer by default.
