## Executive summary

The repository contains older archive folders and the newer AI-native canonical-project-archive structure.

## Bridge rule

Older folders are source and legacy context.

The AI-native structure is the preferred future continuation layer for new canonical summaries.

## Use rule

If an older file conflicts with a newer canonical-project-archive file:

- preserve both
- prefer the newer canonical file for current behavior
- classify the older file as source, legacy, archive-only or superseded
- add a note rather than deleting history

## Operational implication

Migration should be consolidation, not duplication.
