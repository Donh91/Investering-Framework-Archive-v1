# PULLBACK TRACKER v2 GOVERNANCE

Status: Active shadow-governance rule
Date added: 2026-07-05
Effective from: 2026-07-05
Source context: ChatGPT
Applies to: Pullback Tracker, Sequence Ledger, Weekly RAW, Master Monday

## Executive summary

Pullback Tracker is treated as a sequence forecast system in shadow mode.

It tracks how pullbacks develop, stabilize, fail, return or progress.

## Canonical content

Each active pullback sequence should have a PTR ID.

PTR rows should include:

- sequence ID
- creation date
- current stage
- expected next stage
- key invalidation
- outcome state
- review note

## F1/F2 distinction

F1 = mechanical stabilization.
Price stops falling, but internal confirmation is incomplete.

F2 = organic absorption.
Price stabilizes and internals improve.

Only F2 can support stronger recovery interpretation.

## Operational implication

PTR is learning and calibration first. It should inform Master Monday, but not silently override live state.

## Governance notes

Do not convert F1 into recovery without confirmation.
Do not rewrite old PTR expectations.
