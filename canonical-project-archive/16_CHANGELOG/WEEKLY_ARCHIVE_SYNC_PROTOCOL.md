# WEEKLY ARCHIVE SYNC PROTOCOL

Status: Active operational protocol
Date added: 2026-07-05
Effective from: 2026-07-05
Source context: ChatGPT
Applies to: GitHub Archive Sync, weekly operations, changelog

## Executive summary

GitHub Archive Sync should archive material weekly after the main framework chain has run.

It should archive what is material, not everything.

## Weekly sync order

1. Verify repository access.
2. Confirm highest active DATA PING version.
3. Review weekly framework outputs.
4. Identify material changes.
5. Classify each item.
6. Write small dated markdown files.
7. Add changelog entry.
8. Report blocked writes if any.

## Materiality classes

- Canonical archive
- Weekly learning
- Cycle Navigator record
- Research experiment
- Routine noise

## Hard archive triggers

Archive if the item changes governance, source rules, automation behavior, scoring, verified actuals, Research Lab classification, Cycle Navigator template or DATA PING version state.

## Governance notes

Never claim a GitHub write succeeded unless the connector returns success.
