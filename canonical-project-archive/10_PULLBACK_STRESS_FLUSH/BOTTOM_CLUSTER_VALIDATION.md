# BOTTOM CLUSTER VALIDATION

Status: Active diagnostic rule
Date added: 2026-07-05
Effective from: 2026-07-05
Source context: ChatGPT
Applies to: bottom review, flush review, PTR, Master Monday

## Executive summary

A bottom cluster is a candidate zone, not a confirmed bottom.

Validation requires structure after the cluster, not only price touching a level.

## Candidate cluster signals

A candidate bottom cluster may include:

- liquidation concentration
- prior support area
- high-volume reaction
- failed breakdown
- reclaim attempt
- sentiment exhaustion

## Validation requirements

A cluster improves only when several factors confirm:

- reclaim holds
- downside follow-through weakens
- OI does not rebuild aggressively against the move
- funding normalizes
- breadth improves
- ETH/BTC does not collapse
- BTC dominance does not create rotation stress

## Operational implication

Bottom cluster validation can improve recovery-attempt quality, but not automatically confirm recovery.

## Governance notes

Do not use a single cluster touch as rebuy permission.
