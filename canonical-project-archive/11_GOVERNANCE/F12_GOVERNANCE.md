## Executive summary

The ETF-era default assumption must remain falsifiable.

A regime assumption that cannot be falsified becomes belief, not governance.

## Canonical content

F12 exists to prevent the framework from explaining every failed rotation through the same default regime assumption.

ETF-era default should be challenged if multiple rotation sequences survive with:

- persistent breadth improvement
- stable or falling BTC dominance
- ETH/BTC persistence
- improved deployment quality
- no quick return to BTC-only absorption

## Operational implication

If F12 conditions are met, the framework must review whether ETF-era default remains valid.

## Governance notes

F12 is not a buy signal.
It is a worldview check.
It does not override DATA PING or verified actuals.
