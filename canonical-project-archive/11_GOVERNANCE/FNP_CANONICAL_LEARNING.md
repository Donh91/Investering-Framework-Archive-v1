# FNP CANONICAL LEARNING

Status: Canonical learning

Source context: ChatGPT
Applies to: FNP, Research Lab, Forecast Ledger, Cycle Navigator, Master Monday

## Executive summary

False-negative learning must be evaluated within a frozen horizon.

A later outcome must not be pulled backward into an earlier evaluation window.

## Canonical content

FNP tracks opportunity cost and delayed action cost.

Each FNP row should preserve:

- original decision context
- frozen horizon
- what was not done
- expected cost or risk
- actual outcome within horizon
- asset class affected
- whether the miss was genuine
- whether the learning is verified or only hypothesis

## Key learning

FNP must distinguish between:

- verified missed opportunity
- hypothesis under observation
- later outcome outside frozen horizon
- correct restraint

## Operational implication

FNP prevents defensive drift, but it must not become hindsight storytelling.

## Governance notes

FNP is accountability, not automatic permission to increase risk.
